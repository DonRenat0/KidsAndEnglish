🇬🇧 English
Kids And English is a small Android game that helps children learn basic English vocabulary. Each screen shows a picture and the child types its name in English.
What it does
🎮 3 levels, 6 words each (18 total): Animals 🐯, Food 🍞 and Fruits 🍎.
✅ Correct answer: +1 point, a sound effect and the next word. Wrong answer: a hint with the first letters.
👤 Create or select a player; progress is saved with Save & Exit.
🏆 Local ranking of all players by points.
🎉 Victory animation and sounds when the last word is completed.
📴 Works offline (data stored locally with SQLite).
📱 Install on your phone
Requires Android 7.0 (API 24) or higher.
Open the Releases page of this repository on your phone.
Download the latest `app-debug.apk` (or `.apk`) file.
Open it. If Android asks, allow "Install unknown apps" for your browser or file manager.
Tap Install and open Kids And English.
🛠️ Build from source
Install Android Studio.
Clone the repo: `git clone https://github.com/DonRenat0/KidsAndEnglish.git`
Open the folder in Android Studio, wait for Gradle to sync and press ▶ Run.
Tech: Kotlin · Android SDK · SQLite · Lottie

🇪🇸 Español
Kids And English es un pequeño juego para Android que ayuda a los niños a aprender vocabulario básico de inglés. Cada pantalla muestra una imagen y el niño escribe su nombre en inglés.
Qué hace
🎮 3 niveles de 6 palabras (18 en total): Animales 🐯, Comida 🍞 y Frutas 🍎.
✅ Respuesta correcta: +1 punto, efecto de sonido y siguiente palabra. Respuesta incorrecta: una pista con las primeras letras.
👤 Crea o selecciona un jugador; el progreso se guarda con Save & Exit.
🏆 Ranking local de todos los jugadores por puntos.
🎉 Animación y sonidos de victoria al completar la última palabra.
📴 Funciona sin conexión (datos guardados en local con SQLite).
📱 Instalar en el móvil
Requiere Android 7.0 (API 24) o superior.
Abre la página de Releases de este repositorio desde tu móvil.
Descarga el último archivo `app-debug.apk` (o `.apk`).
Ábrelo. Si Android lo pide, permite "Instalar apps desconocidas" para tu navegador o gestor de archivos.
Pulsa Instalar y abre Kids And English.
🛠️ Compilar desde el código
Instala Android Studio.
Clona el repositorio: `git clone https://github.com/DonRenat0/KidsAndEnglish.git`
Abre la carpeta en Android Studio, espera a que Gradle sincronice y pulsa ▶ Run.
